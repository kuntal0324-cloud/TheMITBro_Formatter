# Real Content Production Workspace

This directory begins the post-M45 operational phase.

Use it for original GATE EE and IIT-JEE content only. The formatter architecture is
frozen; new work should primarily be question authoring, ingestion, validation,
review, blueprint configuration and publishing.

- `source_batches/` — original raw question batches
- `review_queue/` — content requiring human review
- `blueprints/` — paper selection specifications
- `releases/` — generated release outputs or release manifests

Do not copy copyrighted exam papers into this repository. Create original
exam-standard questions and use public syllabi/patterns only as structural guidance.
