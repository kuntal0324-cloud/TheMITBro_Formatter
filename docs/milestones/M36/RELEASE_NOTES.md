# M36 Release Notes

Milestone 36 adds the unified visual-question intelligence layer for
TheMITbro Formatter and Question Bank.

Highlights:
- unified mathematical + Electrical Engineering diagram analysis
- conservative image diagram-candidate screening
- automatic visual metadata during question ingestion
- stable diagram fingerprints
- generator dispatch to existing M17/M18 rendering engines
- dedicated M36 GitHub certification workflow

This milestone is intentionally conservative: it recognizes supported diagram
families and routes/generates structured diagrams, but it does not invent
missing topology from an arbitrary image.
