# M35 Release Notes

Milestone 35 adds the Universal Mathematical Recognition layer required for
high-quality GATE EE and IIT-JEE question-bank production.

New capabilities:
- OCR-oriented mathematical normalization
- Unicode-to-LaTeX-compatible normalization
- superscript/subscript reconstruction
- mathematical segment detection
- EE scientific notation normalization
- math-confidence metadata
- Math-aware Question Bank ingestion
- expanded GATE EE and JEE Physics taxonomy
- dedicated CI certification

M36 is reserved for mathematical and Electrical Engineering diagram intelligence:
circuits, phasors, block diagrams, waveforms, graphs, coordinate geometry and
other structured visual question content.
