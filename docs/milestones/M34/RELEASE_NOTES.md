# M34 Release Notes

Milestone 34 turns the M33 OCR scaffold into the first end-to-end Question Bank
ingestion pipeline.

Key changes:
- real text ingestion
- OCR image preprocessing
- Tesseract-backed image OCR
- PNG support
- confidence-based review routing
- normalized duplicate fingerprints and fuzzy similarity
- catalog search
- recursive bulk importer
- dedicated GitHub Actions acceptance workflow

M35 will focus on mathematical OCR/recognition and formula reconstruction.
M36 will focus on mathematical and Electrical Engineering diagram intelligence.
